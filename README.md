# Sentiment Analysis
A machine learning based Sentiment Analysis application that classifies text into three sentiment categories:

- Positive
- Neutral
- Negative

## Project Overview

This project uses a machine learning model to analyze the sentiment of user-provided text. The model was trained using the Twitter sentiment dataset and uses TF-IDF for text feature extraction and Logistic Regression for sentiment classification.
The trained model is integrated with a FastAPI backend and connected to a simple frontend using HTML, CSS, and JavaScript.
